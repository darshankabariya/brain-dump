# AI inference verification

Notes, interactive pages, animations and source documents made while studying how a
zero-knowledge proof can show that an AI model really produced an answer, built around SASH's
open `zk-inference-prover` (github.com/sg-ai-safety-hub/zk-inference-prover), its results
repository, and Pascal Berrang's paper "Zero-Knowledge Model Checking" (arXiv 2605.00487).

Every page is a single HTML file. Download it and open it in a browser; the figures are
interactive. `index.html` is the same index as below, as a page with links.

## How to add or update an entry

The index is generated. Edit `index.json` (one object per page, animation, video or document:
title, kind, file, published page, dates, version, status, what you learn, notes), then run

    python3 tools/build_index.py

from this directory. It rewrites `index.html` and the block between the index markers above.
Commit the three files together. When a page gets a new version, bump `updated` and `version`;
when a mistake is found, add a row to `corrections` and set the entry's `status`.
